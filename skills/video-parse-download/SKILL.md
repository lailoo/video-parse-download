# 视频解析与下载

从用户提供的单条抖音视频链接完成「信息确认 -> 地址解析 -> 文件保存 -> 结果验证」。使用当前环境已配置的浏览器工具；本 skill 不自带解析引擎或浏览器运行时。

## 触发与前置

- 接受 `www.douyin.com/video/<id>`、`v.douyin.com` 分享短链、`iesdouyin.com` 分享页及带 `modal_id` 的页面。未指定视频的个人主页和批量下载不适用。
- 登录要求取决于视频和当前浏览器环境。优先使用已有浏览器会话；遇到必需的登录或人机验证时，交给用户完成。
- 用户指定保存位置时使用该位置，否则使用当前工作目录；浏览器原生下载默认保存到其下载目录，应报告实际路径。

## 工作流

1. **提取视频 ID**：使用 URL 解析接口读取 `modal_id` 或 `/video/<id>` 路径段；短链先通过浏览器跳转得到视频 ID。带 `modal_id` 的收藏页无需先打开列表。收藏弹窗可能自动轮播，始终核对目标 ID。
2. **确认信息**：打开 `https://www.douyin.com/video/<id>`，通过页面快照或截图核对标题、作者、时长与用户目标。此前实测官方网页没有该视频的下载入口，且播放器使用 blob；无需重复尝试同一失败路径。
3. **使用解析站**：打开 `https://dlpanda.com/douyin`，将原链接填入 `Paste Douyin link here`，点击 `Download`。等待结果区出现 `DL_SUCCESS` / `MEDIA READY`，核对返回的标题、作者、视频 ID 与媒体类型。按钮文字若变化，应先观察当前页面。
4. **保存真实文件**：优先点击结果区的 `Download Video`。如果浏览器打开了视频直链而未保存，使用浏览器工具的文件获取能力下载页面已展示的 HTTP(S) 媒体地址，指定可写且未被占用的文件路径。解析出的 CDN 地址有时效，应立即下载。
5. **验证结果**：对照预览时长和本地文件。至少确认实际路径存在、文件字节数大于零且文件类型为视频；可用时用 ffprobe 检查时长与音视频流，用 FFmpeg 完整解码验证。下载清单或文件请求返回值应与磁盘文件交叉核对。

## 浏览器工具适配

- 有原生下载清单时，确认 `state=completed` 和实际文件大小；不要只根据按钮点击、进度弹窗或 `DL_SUCCESS` 宣告下载成功。
- Tabbit CLI 不提供 Playwright 下载事件，因此不要等待 `page.waitForEvent('download')` 或依赖 `downloadsDelta`。对已展示的媒体直链使用 `page.fetch(url, {as: 'file', savePath, timeoutMs: 20000})`，检查 `ok`、`contentType`、`path`、`bytes`，再核验磁盘文件。
- 只有解析成功、文件尚未保存时，明确报告「解析成功，下载未完成」。视频预览直接打开并不等于下载完成。
- 文件名可保留解析站提供的作者和视频 ID。不能覆盖同名文件时，选择新名称并报告实际路径。

## 输出契约

最终报告包含视频标题、作者、视频 ID、媒体类型（VIDEO/AUDIO）、实际文件路径及文件名、字节数、下载状态、来源与验证方法。缺失的字段如实标注未知，不根据示例补全。

## 失败处理

- DLPanda 返回失败时，记录当前错误；可换 `https://snapany.com` 解析一次。该站曾返回 Network error，不能假设一定支持抖音。仍失败则报告原因，必要时请用户提供分享短链。
- 出现登录墙、人机验证或访问限制时，由用户完成所需操作，不绕过验证。
- 原有 E2B 环境中的纯 HTTP 探测多次失败，优先沿用已验证的浏览器路径。历史结果不代表所有网络环境或接口永久不可用。
- 无水印效果取决于返回的源文件，未经检查不要承诺。其他短视频平台尚未验证，不保证通用支持。

需要核对已测视频、浏览器保存方法或旧环境的失败路径时，阅读 [实测记录](references/probe-log.md)。
